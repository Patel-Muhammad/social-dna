Method

Louvain: communities by maximising modularity

  1. Every user starts alone in their own community
  2. Move each user to the neighbour community that raises modularity most
  3. Merge each community into a super-node and repeat
  4. Stop when modularity cannot improve any further

Common-interest analysis

What makes community 1 distinctive

Measured shares of its {{c1_members}} members liking each artist feature, compared with the whole network.

Community 1Whole network

How it is measured

  • prevalence = members liking it ÷ members

  • lift = prevalence ÷ network prevalence

  • distinctive = prevalence × log₂(lift)

Measured, not inferred

Features are anonymous IDs. We never invent artist names or genres.
